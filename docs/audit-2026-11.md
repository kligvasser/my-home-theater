## Test gaps

Each fix carries a regression test. `tests/conftest.py` `SECRET_ENV_VARS` also omits
`DASHBOARD_REQUIRE_AUTH`, `TRANSMISSION_*` and `OPENSUBTITLES_*`, so real env can leak
into tests. `tests/test_cleanup.py` asserts the unsafe orphan behaviour (L3).
`FailingRootFS` raises from `walk()`, which the real library never does (L1).
`tests/test_frontend.py` runs `app.js` under `jsc` (macOS JavaScriptCore) with a stub
DOM (`tests/js/dom_stub.js`); that covers logic, not rendering.
